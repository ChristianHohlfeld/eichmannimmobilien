Exposé Admin

Immobilien Eichmann · für Helmut
Single Source of Truth: Immowelt. Titel, Preis, Status, Referenznummer und Objektdaten kommen ausschließlich von dort. Dieses Admin steuert nur, ob ein Immowelt-Objekt auf unserer Website sichtbar ist.

Anmeldung

Freigeschaltete E-Mail + Passwort. Für Speichern: einmalig GitHub-PAT für diese Sitzung (fine-grained, Contents write). Der Token wird nicht auf der Website gespeichert.

Nicht ins Repo legen. Nach Abmelden weg. Bei Leak: Token bei GitHub widerrufen.

Erweitert

Härte-Modus: kein Token in config.json. Schreibzugriff nur über Sitzungs-PAT beim Login oder hier.

Nur für Notfälle / Rotation – optional ein Sitzungs-Token setzen (nicht persistent).
