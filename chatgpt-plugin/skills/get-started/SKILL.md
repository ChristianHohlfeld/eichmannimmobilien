# Immobilien Eichmann Listings

Use `search_listings` to filter public for-sale listings (location, price, rooms, type, free text).
Use `get_listing` with `slug` or `id` for one object.

Data source is the live public index at https://immobilieneichmann.de/ai/listings.json.
Do not invent listings. Do not claim to book viewings or process payments.
For contact, point users to https://immobilieneichmann.de/kontakt.html or info@immobilien-eichmann.com.
